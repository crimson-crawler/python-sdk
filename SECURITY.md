# Security policy

Do not report suspected vulnerabilities in a public issue.

Use the repository's **Security** tab and select **Report a vulnerability** to open a private security advisory.

Include:

- the affected file or documented endpoint and the relevant package, release, documentation, or server version identifier (`server.json` for the MCP server);
- reproduction steps or a proof of concept;
- the expected and observed behavior;
- any known impact or mitigations.

Do not include live credentials, customer data, or destructive payloads. Maintainers will coordinate validation, remediation, and disclosure in the private advisory.
